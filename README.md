# 猫娘嘲讽·杂鱼

> 「猫娘还没到？没关系，杂鱼♡ 我可以先骂着等你。」

给 [N.E.K.O](https://github.com/Project-N-E-K-O/N.E.K.O) 的猫娘加一整柜**中 / 日 / 英 / 韩**嘲讽台词。以日语雌小鬼（メスガキ）台词为主：`ざぁこ♡`、`杂鱼♡`、`zako♡`、`자코♡`。

不是让模型自由发挥，而是把**手写的、可审计的台词**递给她：她会保留自己的称呼和语气，把指定那一句说出来。台词库 146 句，日语 70 句，其余三语覆盖同样的情绪分类。

- 插件 ID：`neko_taunt`
- 版本：`1.0.0`
- 类型：普通 Plugin（Python，独立进程）
- 依赖：无（只用标准库 + N.E.K.O 插件 SDK）
- 联网：**没有**。不读聊天、不读屏幕、不写文件
- 市场状态：首次审核已提交（submission `219`），自动检查 `passed`，等待人工审核；
  GitHub Release `v1.0.0` 已就绪。审核通过后才会生成 Market stable 版本。

## 它能做什么

| 能力 | 说明 |
|---|---|
| 指定语言 | `auto` / `ja` / `zh` / `en` / `ko` / `mix`（mix 以日语为主，约 60%） |
| 指定情绪 | 杂鱼、手笨、磨蹭、输了、还没到、黏人、嘴硬夸奖 |
| 指定强度 | 1 轻飘飘 / 2 标准雌小鬼 / 3 更欠揍（仍然只是玩闹） |
| 结合情境 | 说「我游戏输了」「等你等太久」，自动选分类并把情境带进提示 |
| 不连续重复 | 进程内记住最近 12 句，抽完一轮才会重复 |
| 定时自动嘲讽 | **默认关闭**；开启后受间隔、次数上限、免打扰时段限制 |
| 语录库 / 预览 | 不触发对话，先看统计和例句 |
| 四语言 i18n | 插件名、描述、按钮、配置项说明都有中/英/日/韩 |

### 四语言示例

| 语言 | 台词 | 中文意思 |
|---|---|---|
| 日语 | 「ふふっ、ざぁこ♡ ざぁこ♡」 | 呵呵，杂鱼♡ 杂鱼♡ |
| 日语 | 「まだ猫娘が来ないの？ ざぁこ♡ 待つしかないね♡」 | 猫娘还没来？杂鱼♡ 只能等着呢♡ |
| 中文 | 「杂鱼♡ 杂鱼♡ 就这？」 | — |
| 英语 | "Ehh~? That's all, zako♡" | 诶～？就这？杂鱼♡ |
| 韩语 | 「에~? 이게 전부야? 자코♡」 | 诶～？就这？杂鱼♡ |

完整台词库：日语 70、中文 31、英语 24、韩语 21，共 **146** 句。

## 安装

### 从插件市场（推荐）

1. 打开 **N.E.K.O → 插件管理 → 插件市场**，搜索「猫娘嘲讽」或「杂鱼」。
2. 安装后启用「猫娘嘲讽·杂鱼」。
3. 首次安装如果宿主询问自动启动，按你的习惯选择；插件默认**不会**主动开骂。

### 从 `.neko-plugin` 包

1. **插件管理 → 导入**，选择 `neko_taunt.neko-plugin`。
2. 启用插件。
3. 对猫娘说「骂我一句」测试。

> 源码开发：把本目录放到 `N.E.K.O/plugin/plugins/neko_taunt/`，刷新插件列表并启动。
> 运行数据在用户数据目录的 `plugins/neko_taunt/`，不会写回源码目录。

## 用法

直接对猫娘说：

- 「骂我一句」
- 「嘲讽我」
- 「叫我杂鱼」
- 「用日语嘲讽我」
- 「用韩语骂我一句」
- 「猫娘还没到，说点什么」
- 「我游戏输了，嘲讽我」
- 「来点雌小鬼台词」
- 「四种语言各来一句」
- 「先预览一句，别真的说」
- 「给我看看都有什么台词」
- 「每 20 分钟嘲讽我一次」/「别骂了」

猫娘会调用 `neko_taunt` 工具取一句，然后用她自己的声音说出来。她不会把整段提示念出来，也不会突然改成安慰——除非你说「温柔点」。

### 插件入口

| 入口 ID | 用途 | 是否主动推送 |
|---|---|---|
| `taunt_now` | 取一句给当前对话说（Agent 路由 / 工具） | 否 |
| `taunt_speak` | 让猫娘单独起一轮主动嘲讽（插件中心按钮） | 是 |
| `taunt_preview` | 预览一句 + 同分类例子 | 否 |
| `taunt_library` | 语录库统计与示例 | 否 |
| `taunt_status` | 配置、计数、最近用过的 id | 否 |
| `taunt_mode` | 开关定时自动嘲讽、改间隔 | 否 |
| `neko_taunt`（LLM 工具） | 对话期取台词 | 否 |

> 已经有对话回合时不要同时点 `taunt_speak`，否则会多出一轮。对话里优先用 `taunt_now` / `neko_taunt`。

## 配置

在 **插件管理 → 猫娘嘲讽·杂鱼 → 配置** 里修改，或编辑用户数据目录的
`plugins/neko_taunt/config/plugin.toml`：

| 键 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `default_language` | `ja` | `auto`/`ja`/`zh`/`en`/`ko`/`mix` | 默认语言 |
| `default_intensity` | `2` | 1–3 | 默认强度 |
| `auto_taunt` | `false` | bool | 定时自动嘲讽 |
| `auto_taunt_interval_minutes` | `20` | 5–180 | 自动嘲讽间隔 |
| `auto_taunt_max_per_session` | `8` | 1–50 | 每次会话上限 |
| `auto_taunt_category` | `auto` | 分类 / auto | 自动模式偏好 |
| `quiet_hours` | `23:00-08:00` | `HH:MM-HH:MM` / 空 | 免打扰时段 |
| `include_romaji` | `true` | bool | 提示里带日语罗马音 |
| `include_translation` | `true` | bool | 提示里带中文释义 |

配置面板的字段说明支持中 / 英 / 日 / 韩（`config.schema.json` 的 `x-title-i18n` / `x-description-i18n`）。

## 安全边界与内容政策

这是**玩闹式嘲讽**，不是攻击工具。台词库只包含「杂鱼」「笨蛋」「菜」「慢」这类轻量词，没有脏话、仇恨词、性暗示或威胁。

插件递给模型的提示里固定包含：

> 只许玩闹式嘲讽：不许人身攻击、外貌/身材/家庭/创伤、歧视、性暗示、威胁或诅咒。
> 主人说停、说不想听、或者情绪不对时立刻收住，换成正常语气。

自动嘲讽是显式 opt-in，并且：

- 最短间隔 5 分钟，默认 20 分钟；
- 每次会话最多 8 次；
- 默认 23:00–08:00 免打扰；
- 推送失败不刷屏；
- 说「别骂了」或关闭开关立即停止。

## 隐私

- **不联网**：没有 HTTP / socket 客户端，不请求任何外部服务。
- **不读聊天记录、屏幕、剪贴板、文件**。
- **不保存对话内容**：只在内存里保留最近用过的台词 id（防重复）和本次自动嘲讽次数。
- **不改人设**：插件只提供台词素材和一句交付说明，最终语气由猫娘自己决定。

## 已知限制

- 台词是固定集合，不会自己生成新句子；想要新台词需要更新版本。
- `mix` 是「按权重抽语言」，不是四语逐句翻译。
- 猫娘最终说出来时可能加一个语气词或猫叫；插件要求她保留原句，但不保证 TTS 的停顿完全一致。
- 自动模式会主动发起对话；在会议 / 直播 / 深夜请关闭。
- 插件不判断主人真实情绪；如果你今天真的难过，直接说「别骂了，抱抱我」。
