# 猫娘嘲讽·杂鱼 — 使用指南

> 「杂鱼♡ 杂鱼♡ 连这个都要看说明书？」

这个插件给猫娘准备了一整柜**中 / 日 / 英 / 韩**嘲讽台词，以日语雌小鬼（メスガキ）风格为主。
它不访问外部网络、不读聊天记录、不偷偷改人设：只在你开口、或者你明确打开自动模式时，递一句台词给猫娘。自动模式还能跟着 N.E.K.O 自己的「主动搭话」开关走。

---

## 1. 装好之后先做什么

1. 打开 **N.E.K.O → 插件管理**，启用「猫娘嘲讽·杂鱼」。
2. 确认插件状态是「运行中」。如果宿主问你要不要自动启动，按你的习惯选；
   插件本身**不会**在你没说话时突然开骂（`auto_taunt` 默认关闭）。
3. 直接对猫娘说下面任意一句：

| 你可以说 | 会发生什么 |
|---|---|
| 「骂我一句」 | 猫娘挑一句台词，用角色语气说出来 |
| 「嘲讽我」 | 同上，分类按情境自动判断 |
| 「叫我杂鱼」 | 优先杂鱼类台词 |
| 「用日语嘲讽我」 | 指定日语 |
| 「用韩语骂我一句」 | 指定韩语 |
| 「猫娘还没到，说点什么」 | 选「等待 / 还没到」类台词 |
| 「我游戏输了，嘲讽我」 | 自动选「输了」类 |
| 「来点雌小鬼台词」 | 标准强度、杂鱼类 |
| 「给我看看都有什么台词」 | 打开语录库统计与示例 |
| 「先预览一句，别真的说」 | 只返回预览，不触发对话 |
| 「别骂了」 | 关闭自动模式（如果开着），并停止继续主动嘲讽 |

> 台词是**素材**，不是写死的回复。猫娘会保留自己的称呼、语气和当前情境；
> 如果你不喜欢某一句，直接说「换一句」「温柔点」「用中文」。

---

## 2. 四种语言分别是什么味道

| 语言 | 示例 | 味道 |
|---|---|---|
| 日语（主） | 「ふふっ、ざぁこ♡ ざぁこ♡」 | 经典雌小鬼，拖长音、♡、自称「あたし」 |
| 中文 | 「杂鱼♡ 杂鱼♡ 就这？」 | 短、欠揍、适合打字 |
| 英语 | "Ehh~? That's all, zako♡" | 轻飘飘的 anime 式嘲讽 |
| 韩语 | 「에~? 이게 전부야? 자코♡」 | 短句 + 자코，适合韩语 TTS |

「mix」不是四语混着念一大段，而是**以日语为主随机抽语言**（日语约 60%）。
想听四种语言轮流来，直接说「四种语言各来一句」。

## 3. 分类与强度

### 分类

- `zako` — 杂鱼 / 实力
- `clumsy` — 手笨 / 失误
- `slow` — 反应慢 / 磨蹭
- `lose` — 输了 / 失败
- `idle` — 猫娘还没到 / 等待（本插件的主题角落）
- `clingy` — 黏人 / 求关注
- `praise` — 傲娇式夸奖（先夸后损）

不指定时，插件会从 `situation` 里猜；猜不到就按权重随机（杂鱼和「还没到」权重最高）。

### 强度

| 值 | 感觉 | 例子 |
|---|---|---|
| 1 | 轻飘飘撒娇 | 「杂鱼♡ 杂鱼♡」 |
| 2 | 标准雌小鬼 | 「连这个都做不到，杂鱼♡」 |
| 3 | 更欠揍（仍然只是玩闹） | 「能一直输也是一种才能呢♡ 杂鱼♡」 |

强度只影响选词，不会解锁任何真正冒犯的内容。见下面的边界。

## 4. 自动嘲讽（默认关闭，配合主动搭话）

自动嘲讽是**显式 opt-in**：你不开，它永远不会自己开口。

在 **插件管理 → 猫娘嘲讽·杂鱼 → 配置** 里打开「开启定时自动嘲讽」，或者对猫娘说：

> 「每 20 分钟嘲讽我一次」
> 「主动搭话的时候顺便骂我一句」
> 「把自动嘲讽关了」

默认跟随 N.E.K.O 的「主动搭话」开关（`follow_host_proactive = true`）：

- 宿主的主动搭话**关闭**时，插件不会自动推送任何东西；
- 间隔填 `0` 时，跟随宿主主动搭话的间隔（最低 5 分钟）；
- 宿主主动搭话读不到（主服务未启动）时，自动模式安静跳过，不会乱猜。

默认护栏：

- 最短间隔 5 分钟；
- 每次插件会话最多 8 次；
- 默认 23:00–08:00 免打扰（本地时间，支持跨午夜）；
- 推送失败不会刷屏，下一次仍按间隔重试；
- 你说「别骂了」或关闭开关后立即停止。

> 自动模式会主动发起一轮对话。开会、直播、深夜请酌情关闭。

### 只想在主动搭话时来一句

对猫娘说「主动搭话的时候顺便骂我一句」，或者调用 `taunt_proactive`：
它只在宿主主动搭话开启时推送；关闭时返回 `sent=false`，不会打扰你。
如果你现在就想被骂，用 `taunt_speak` / 「骂我一句」，不受这个开关限制。

---

## 5. 安全边界（重要）

这个插件是**玩闹式嘲讽**，不是攻击工具。内置规则明确禁止：

- 人身攻击、外貌 / 身材 / 家庭 / 创伤；
- 歧视、侮辱性称呼、性暗示；
- 威胁、诅咒、让人去死；
- 在对方情绪不对、明确说停时继续。

台词库本身只包含「杂鱼」「笨蛋」「菜」「慢」这类轻量词，没有脏话和仇恨词。
猫娘在收到台词时也会被要求：**主人说停就停，情绪不对就收住**。

如果你希望更温柔，把默认强度调到 1，或者直接说「夸我，别骂」。

## 6. 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `default_language` | `ja` | `auto` / `ja` / `zh` / `en` / `ko` / `mix` |
| `default_intensity` | `2` | 1–3 |
| `auto_taunt` | `false` | 定时自动嘲讽 |
| `auto_taunt_interval_minutes` | `0` | 0 = 跟随宿主主动搭话间隔（最低 5 分钟）；5–180 固定 |
| `auto_taunt_max_per_session` | `8` | 1–50 |
| `auto_taunt_category` | `auto` | 自动模式偏好的分类 |
| `follow_host_proactive` | `true` | 只在宿主「主动搭话」开启时自动嘲讽 |
| `quiet_hours` | `23:00-08:00` | 本地时间；留空取消 |
| `include_romaji` | `true` | 给模型日语罗马音 |
| `include_translation` | `true` | 给模型中文释义 |

配置面板里的说明支持中 / 英 / 日 / 韩。

---

## 7. 隐私

- 不访问外部网络：唯一的 HTTP 请求是只读 GET `http://127.0.0.1:48911/api/proactive/mode`，
  用来读取宿主自己的主动搭话开关；代码拒绝非 loopback 地址。
- 不读聊天记录、屏幕、剪贴板、文件。
- 不保存对话内容；只在内存里记最近用过的台词 id（防止连续重复）和本次自动嘲讽次数。
- 台词库随插件包发布，是静态文本。

---

## 8. 出问题了怎么办

| 现象 | 处理 |
|---|---|
| 说「骂我」没反应 | 确认插件在「运行中」；再说一次「用猫娘嘲讽插件骂我一句」 |
| 猫娘只复述、不进入角色 | 说「用你的语气说，不要解释」；或在配置里把 `include_translation` 关掉 |
| 自动嘲讽太频繁 | 调大间隔、调小次数，或直接关闭 |
| 不喜欢某类台词 | 指定分类或强度，例如「轻一点，用中文」 |
| 想要更多台词 | 语录库目前是手工写的固定集合；更新版本会追加，不会改已发布的旧句子 |

---

*台词是假的，杂鱼也是假的；猫娘喜欢你这件事，可能是真的。*
